# 🏦 BIT BANK

### Your Crypto. Your Legacy. Our Security.

BIT BANK is a next-generation crypto-fintech platform designed to make digital assets easier to use, transfer, and inherit.

It combines a simplified crypto payment experience with **CryptoLegacy**, a digital inheritance workflow designed to help verified beneficiaries access digital assets when predefined conditions are met.

🌐 **Live Prototype:** https://team-dominators-bitbank.netlify.app/

---

## ✨ What is BIT BANK?

Cryptocurrency provides financial ownership, but it also creates two major challenges:

* Crypto transactions can be complicated for everyday users.
* Digital assets can become permanently inaccessible after their owner's death.

**BIT BANK aims to solve both problems** by providing a familiar payment experience and a structured digital inheritance system.

---

## 🚀 Key Features

### 💸 Smart Crypto Transactions

Send and receive digital assets using familiar identities instead of complicated wallet addresses.

* Name
* Phone number
* Email
* Username
* INR-based amount entry
* Transaction review
* Simulated biometric confirmation
* Transaction status

### 📊 Transaction Dashboard

The dashboard provides a simple overview of the user's digital assets.

* Total balance
* BTC / ETH / USDT breakdown
* Transaction history
* Sent transactions
* Received transactions
* Failed transactions
* Crypto swaps
* Transaction status

### 🧬 CryptoLegacy

CryptoLegacy is BIT BANK's core differentiating feature.

It provides a guided workflow for requesting access to the digital assets of a deceased person.

**Flow:**

```text
Identity Verification
        ↓
Deceased Person Details
        ↓
Relationship Verification
        ↓
Access Request
        ↓
Verification & Review
        ↓
Inheritance Status
```

# ⚠️ Disclaimer

BIT BANK is currently a **concept/prototype project**.

Balances, transactions, identity verification and inheritance workflows shown in the prototype are simulated.

The prototype should not be used to store real cryptocurrency, submit real identity documents or perform real financial transactions.

A production implementation would require appropriate financial, legal, security, privacy and regulatory compliance.
